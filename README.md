## 📝 Customization

### Update Personal Information

1. **Contact Information**: Edit the contact section in `index.html`
2. **About Section**: Update the about text in the About section
3. **Skills**: Modify the skills in the Skills section
4. **Experience**: Add your work experience in the Experience section
5. **Projects**: Add your projects in the Projects section

### Color Scheme

The color scheme can be customized by modifying CSS variables in `styles.css`:

```css
:root {
    --primary-color: #2563eb;
    --primary-dark: #1e40af;
    --secondary-color: #64748b;
    /* ... more variables */
}
```

## 🚀 Deployment to GitHub Pages

1. **Create a GitHub Repository**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/yourusername/yourusername.github.io.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**
   - Go to your repository settings
   - Navigate to "Pages" in the left sidebar
   - Under "Source", select "main" branch
   - Click "Save"

3. **Your site will be live at**: `https://yourusername.github.io`
